# 디데이 & 투두 (PWA)

디데이 관리와 투두리스트를 하나로 합친 모바일용 웹 앱입니다. 빌드 과정 없이 정적 파일만으로 동작합니다.

## 기능
- **디데이**: 이벤트 이름과 날짜를 입력해 여러 개 추가/삭제. 오늘 기준 `D-n` / `D-Day` / `D+n` 표시 (다가오는 순 정렬, 지난 이벤트는 아래쪽에 회색으로)
- **투두**: 할 일 추가, 체크로 완료 처리, 삭제. "할 일"과 "완료" 섹션으로 나눠 표시, 완료 항목 일괄 비우기
- 하단 탭으로 두 기능 전환 (마지막으로 본 탭 기억)
- 모든 데이터는 `localStorage`에 저장되어 새로고침해도 유지
- 서비스 워커로 오프라인에서도 실행

## 파일 구성
| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 |
| `style.css` | 모바일 최적화 스타일 (다크 모드 지원) |
| `app.js` | 디데이/투두 로직, 로컬 스토리지 저장 |
| `manifest.json` | PWA 매니페스트 (이름, 아이콘, standalone 모드) |
| `sw.js` | 서비스 워커 (오프라인 캐시) |
| `icons/` | 앱 아이콘 (192, 512, maskable 512) |

## 실행
```bash
cd dday-todo
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 안드로이드 홈 화면에 추가하기
PWA 설치와 서비스 워커는 **HTTPS**(또는 localhost)에서만 동작합니다.

1. GitHub Pages 등 HTTPS 정적 호스팅에 `dday-todo` 폴더를 배포합니다.
   (예: 저장소 Settings → Pages에서 브랜치를 선택하면 `https://<아이디>.github.io/<저장소>/dday-todo/`로 접속 가능)
2. 안드로이드 크롬에서 해당 주소를 엽니다.
3. 메뉴(⋮) → **홈 화면에 추가** 또는 **앱 설치**를 누릅니다.
4. 홈 화면 아이콘으로 실행하면 주소창 없이 앱처럼 열립니다.
